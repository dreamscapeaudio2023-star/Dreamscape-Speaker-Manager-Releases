# Dreamscape Speaker Manager · Dreamscape VSC

Dreamscape Speaker Manager와 Dreamscape Virtual Sound Card의 **공개 매뉴얼 및 향후 다운로드 페이지**입니다. 이 저장소에는 제품 소스 코드가 없습니다.

현재 공개된 것은 [한국어 사용 설명서](MANUAL_ko.md)와 해당 [PDF 릴리스](https://github.com/dreamscapeaudio2023-star/Dreamscape-Speaker-Manager-Releases/releases)입니다. `0.22.0-internal11` 설치 파일과 VSC 드라이버는 내부 시험판이며 **공개 다운로드로 제공하지 않습니다.**

VSC에 사용된 Steinberg ASIO SDK의 비공개 제품 배포 계약이 아직 체결되지 않았습니다. [Steinberg 개발자 안내](https://www.steinberg.net/developers/)와 패키지에 포함된 SDK 라이선스의 공개 배포 조건이 충족되면 설치 파일을 별도 릴리스로 게시할 예정입니다. 라이선스 확인 전에는 이 저장소의 매뉴얼을 공개 설치 가능 상태의 보증으로 해석하지 마세요.

Windows 11 x64와 48 kHz를 대상으로 작성했습니다. 실제 물리 출력 장치·스피커 운용 적합성은 장치별 검증이 필요합니다.
